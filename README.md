# Taco Bell Training Game

A simple Python game built with Tkinter where you practice building customer orders perfectly. Read the customer ticket, assemble the order using the menus, and serve the exact items requested

## Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

## How to Run

1. Open a terminal or command prompt.
2. Navigate to the project directory.
3. Run the game with:

   ```bash
   python main.py
   ```
4. When met with the login screen, enter your username (admin) and password (password). 
5. Click "Start Game" to begin.

## How to Play

Upon entering the game, you will be met with a screen that has a customer photo and an order ticket. Review the order ticket carefully to see what the customer wants. Use the buttons in the "Menu Operations" section below to build the exact order requested (Mains, Drinks, Sides, and Sauces).

As you select items, they will appear in your "Current Tray." If you make a mistake, simply select the incorrect item in the tray and click "Remove Selected." Once your tray perfectly matches all the items on the ticket, click the "SERVE ORDER" button to complete the level and receive the next customer.
