# Taco Bell Training Simulator (TKinter)

Simple Python/Tkinter scaffold for a training "game" with:

- Full-screen login screen (blocks progress until correct credentials)
- Main menu with a figlet-style ASCII banner and three buttons: Start Training, Settings, Exit

Default credentials (change in `main.py`):

- username: `trainee`
- password: `tacobell`

Run:

```bash
python3 main.py
```
